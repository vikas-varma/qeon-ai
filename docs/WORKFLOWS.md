# Screen and product workflows

## First launch

Splash → Onboarding → Sign in → Home

## Chat

Home prompt → Chat → optional file/voice input → streamed response → copy/save/create task.

## Agent

Agents → Agent detail → enable agent → review permissions → chat with agent.

## Scheduled task

Tasks → New task → instruction → schedule → review → save → worker executes → notification → task run details.

## Memory

Profile → Memory & Personalization → category → view/edit/delete memory.

Memory is never hidden from the user. Every stored memory should expose its source and deletion control.

## Connected app

Profile → Connected Apps → provider → OAuth consent → connection result → permissions management → disconnect.

## Side-effect confirmation

Agent proposes action → preview details → user confirms → backend performs action → result and audit entry.
